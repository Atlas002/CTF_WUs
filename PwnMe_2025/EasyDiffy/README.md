## Write up  



### 1. Understanding the Diffie-Hellman Setup

The challenge code ([source.py](src/source.py)) shows a Diffie-Hellman–like key exchange with:

```python
p = getPrime(1536)     # Large 1536-bit prime
g = p - 1             # Base = p - 1
a = getPrime(1536)    # Private key a
b = getPrime(1536)    # Private key b

A = pow(g, a, p)      # A = g^a mod p
B = pow(g, b, p)      # B = g^b mod p
C = pow(B, a, p)      # Shared secret
```

Normally, $g$ (the generator) is a smaller number like 2 or 5. Here, however, $g$ is chosen as $p - 1$. Modulo $p$, $p - 1$ is equivalent to $-1$. This fact alone is the key observation.

---

### 2. Why $g = p - 1$ Becomes $-1 \bmod p$

Mathematically, in modular arithmetic:

$$
p - 1 \equiv -1 \pmod{p}.
$$

So whenever we see $g = p - 1$ in an exponentiation modulo $p$, we can rewrite:

$$
g \equiv -1 \pmod{p}.
$$

---

### 3. Analyzing $A = g^a \bmod p$

Because $a$ is generated by `getPrime(1536)`, it’s almost certainly an odd number (the only even prime is 2, and that’s obviously not 1536 bits). Thus:

1. If $a$ is odd, $(-1)^{\text{odd}} = -1$.
2. If $a$ were even, $(-1)^{\text{even}} = +1$.

Hence, for an odd $a$:

$$
A = g^a \bmod p
  = (p - 1)^a \bmod p
  = (-1)^a \bmod p
  = -1 \bmod p
  = p - 1.
$$

Similarly, $B = g^b \bmod p = p - 1$ assuming $b$ is also an odd prime.

---

### 4. The Shared Secret $C$

Once Alice and Bob calculate $A$ and $B$, they compute the shared secret:

$$
C = B^a \bmod p = (p - 1)^a \bmod p.
$$

But as we just reasoned:

* If $a$ is odd, $(p - 1)^a \equiv -1 \pmod{p}$.
* So $C = p - 1$.

The challenge also asserts `assert pow(A, b, p) == pow(B, a, p)`, which implies both sides match; indeed, they match at $p - 1$.

Thus, the shared secret $C$ is effectively $(p - 1)$ in modulo $p$ arithmetic.

---

### 5. Deriving the AES Key

With the shared secret $C = p - 1$ known, the code does:

```python
key = long_to_bytes(C)      # Convert the shared secret to bytes
key = sha256(key).digest()  # SHA-256 hash
key = key[:16]              # Take the first 16 bytes
```

So the actual 128-bit AES key is just:

$$
\text{AES key} = \text{sha256}\bigl((p - 1)\bigr)[0 : 16].
$$

---

### 6. Decrypting the Ciphertext

The challenge provides the final ciphertext in hex:

```
ciphertext = f2803af955eebc0b24cf872f3c9e3c1fdd072c6da1202fe3c7250fd1058c0bc810b052cf99ebfe424ce82dc31a3ba94f
```

Once we know the AES key, we can create an AES-ECB cipher object and decrypt:

```python
from hashlib import sha256
from Crypto.Cipher import AES
from Crypto.Util.Padding import unpad

shared_secret = p - 1

# 1) Convert shared_secret to bytes
# 2) SHA-256 hash it, take first 16 bytes
key = sha256(shared_secret.to_bytes((shared_secret.bit_length() + 7)//8, 'big')).digest()[:16]

cipher = AES.new(key, AES.MODE_ECB)
plaintext_padded = cipher.decrypt(bytes.fromhex(ciphertext_hex))
plaintext = unpad(plaintext_padded, AES.block_size)
```

This recovers the plaintext, which is the flag:

```
PWNME{411_my_h0m13s_h4t35_sm411_Gs}
```

By noticing that $g = p - 1$ is $-1 \bmod p$, and that the exponents $a$ and $b$ are (with overwhelming probability) odd, we see the Diffie-Hellman exchange collapses to a single value $(p - 1)$. Hashing this value and using it as an AES key unlocks the ciphertext to reveal the flag:
